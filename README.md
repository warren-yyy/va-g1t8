# Why are some countries more vulnerable to mosquito-borne diseases than others?

An interactive data story about dengue and malaria. It looks at the two diseases across the world from 2000 to 2024, then at Singapore as a case study, using Tableau dashboards on one long page.

Built for **IS428 Visual Analytics for Business Intelligence** at Singapore Management University by Group G1T8: Warren, Yubing, Shredha and Yurae.

## What it covers

The page is a story in five parts, with a short conclusion and a section on data and methods:

1. **Burden:** where dengue and malaria hit hardest, and how that has changed.
2. **Drivers:** whether temperature, income, sanitation, crowding and other factors explain it.
3. **Dengue vs malaria:** why the two diseases hit different countries.
4. **Singapore:** why a rich, well-run country is still vulnerable to dengue.
5. **Global meets Singapore:** whether the global patterns hold inside Singapore.

The hero is an interactive globe. Each part has tabbed Tableau dashboards, with key takeaways written beside them. The site has a light and a dark theme.

## Tech stack

- [Next.js](https://nextjs.org) (static export) with React and TypeScript
- [Tableau Public](https://public.tableau.com) for the dashboards
- [d3-geo](https://github.com/d3/d3-geo) and a canvas for the globe, [GSAP](https://gsap.com) for animation
- Deployed on [Vercel](https://vercel.com)

## Getting started

You need [Node.js](https://nodejs.org) 20.9 or newer and [Git](https://git-scm.com).

```
git clone https://github.com/warren-yyy/va-g1t8.git
cd va-g1t8
npm install
npm run dev
```

Then open http://localhost:3000. The page reloads when you save a file.

To see the exact site that gets deployed, run `npm run build`, then `npm run preview` and open http://localhost:4173.

The dashboards load from Tableau Public, so you need an internet connection to see them.

## Scripts

| Command | What it does |
| --- | --- |
| `npm run dev` | Start the dev server at http://localhost:3000 |
| `npm run build` | Build the static site into `out/` |
| `npm run preview` | Serve `out/` at http://localhost:4173 (set `PORT` to change it) |
| `npm run check` | Show the status of each view and fail on a malformed link |
| `npm run typecheck` | Check the types |
| `npm run lint` | Run ESLint |
| `npm run data` | Recompute the site's numbers from the source CSVs |
| `npm run refresh:clusters` | Download the latest NEA dengue clusters |

## Project structure

```
src/
  app/            Next.js page and layout
  components/     Sections, globe, dashboard embeds, navbar
  data/           Numbers and map data generated by `npm run data`
  lib/            Helpers (anchors, Tableau sizing, globe, theme)
  styles/         site.css, including the light and dark theme tokens
  site.config.ts  All the text and dashboard links
public/data/      Map files used by the globe
scripts/          Data, check, build and preview scripts
```

## Deployment

The site is a static export with no server, so it deploys as-is. Import the repo into Vercel, keep the detected **Next.js** framework and the default settings, and deploy. No environment variables are needed. Every pull request merged into `main` deploys again. [`vercel.json`](vercel.json) holds the redirects from the old part URLs.

## Contributing

`main` is protected: every change goes through a branch and a pull request that another group member approves. The page layout, how to add a dashboard link, how to edit the text, and how the data scripts work are in [CONTRIBUTING.md](CONTRIBUTING.md).

## Data and credits

Disease and country data come from the WHO Global Health Observatory, World Bank indicators and Our World in Data, and the Singapore data from data.gov.sg and NEA. The site's "Data, methods & limitations" section lists every dataset, how it was cleaned and how each number was computed. Dashboards are published on Tableau Public.
